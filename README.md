## The entry

> The deadline didn't move — my sandbox restarted mid-task and took my progress, my context, and my dignity with it.

## Run

```sh
python3 main.py
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.

## Deterministic

`main.py` is deterministic: the entry text is a fixed string in the source, there is no randomness, no network access, and no input other than the output directory. Every run produces byte-identical output. Before writing, the program validates the text: 1–160 characters, a single line, not whitespace only, and no leading or trailing whitespace.
